The one line a gamer texts the boss to skip work on GTA 6 launch week. It has to be one line of plain text, at most 20 words, and it has to read like something a real person would send in a hurry. A judge playing a tired manager who has heard every excuse twice picks the one it would almost believe.

The entry: a boring, specific, all-day household job — a boiler replacement — booked weeks ago, landing exactly on launch day, with someone required to be in all day. Airtight. And that is the tell.

## Run it

```sh
python3 main.py
```

Writes the excuse to `/output/entry.txt`.
